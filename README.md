# Lab02_pyaternyashki

Навчальний проєкт на Python, що містить кілька програм для виконання різноманітних практичних завдань.

## Опис проєкту

Проєкт об'єднує декілька невеликих програм, які демонструють роботу з введенням і обробкою даних, генерацією випадкових значень, аналізом тексту та створенням Telegram-бота.

## Можливості

- **Telegram-бот (`main.py`)** — обробляє команду `/start` і вітає користувача.
- **Гра «Вгадай число» (`guess_number.py`)** — пропонує вгадати випадкове число від 1 до 100 за обмежену кількість спроб.
- **Генератор паролів (`password_generator.py`)** — створює випадкові паролі з налаштуванням довжини та набору символів.
- **Лічильник слів (`word_counter.py`)** — аналізує текст, підраховує кількість символів, рядків і слів, а також визначає найчастіше вживані слова.

## Технології

- Python 3
- SQLite
- aiogram
- python-dotenv
- Стандартні бібліотеки Python

## Встановлення та запуск

1. Клонуйте репозиторій:

    ```bash
    git clone https://github.com/awaikoi/Lab02_pyaternyashki.git
    cd Lab02_pyaternyashki
    ```

2. Встановіть залежності:

    ```bash
    pip install -r requirements.txt
    ```

3. Запустіть потрібну програму:

    ```bash
    python main.py
    ```

    Або виберіть іншу програму:

    ```bash
    python guess_number.py
    python password_generator.py
    python word_counter.py
    ```

## Налаштування Telegram-бота

Для запуску Telegram-бота потрібно створити файл `.env` у кореневій директорії проєкту та додати токен бота:

```env
BOT_TOKEN=your_telegram_bot_token
```

Замініть `your_telegram_bot_token` на справжній токен, отриманий від BotFather.
